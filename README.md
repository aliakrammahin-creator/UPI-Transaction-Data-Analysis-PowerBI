                               # UPI Digital Payments Analysis Dashboard | Power BI

## Project Overview
This project is an interactive **UPI Digital Payments Analysis Dashboard** developed in **Power BI** to analyze digital payment transactions and uncover valuable business insights. The dashboard enables users to explore transaction patterns, compare monthly performance, analyze city-wise transactions, and filter data using multiple interactive slicers.
The project demonstrates data transformation, data modeling, DAX calculations, dashboard design, and interactive report development using Power BI.

---

## Project Objectives
- Analyze monthly UPI transaction trends.
- Compare transaction amounts across different cities.
- Monitor remaining account balances.
- Explore customer demographics.
- Provide an interactive experience through slicers, bookmarks, and navigation buttons.

## Dashboard Features

### Interactive Filters
Users can filter the dashboard using:
- Bank Name (Sender)
- Bank Name (Receiver)
- City
- Device Type
- Gender
- Age Groups
- Merchant Name
- Payment Method
- Purpose
- Transaction Type

### Transaction Trend Analysis
The dashboard displays monthly transaction amounts for the year 2024.
Users can switch between multiple visualizations using bookmarks:
- Line Chart – Transaction Amount
- Column Chart – Transaction Amount
- Line Chart – Remaining Balance
- Column Chart – Remaining Balance

### City-wise Transaction Analysis
A Matrix visual compares multiple cities by displaying:
- Monthly Transaction Amount
- Remaining Balance

Conditional formatting is applied to improve readability and highlight important values.
